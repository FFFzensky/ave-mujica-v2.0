# Folder video

Taruh file MP4 music video di sini (file ini tidak ikut ke GitHub).

Nama file harus sama dengan kolom `'video'` di `data/songs.php`, contoh:

| File                               | Lagu                          |
|------------------------------------|-------------------------------|
| black-birthday.mp4                 | Black Birthday (黒のバースデイ) |
| two-moons.mp4                      | Two Moons ~Deep Into The Forest~ |
| choir-s-choir.mp4                  | Choir ‘S’ Choir               |
| kamisama-baka.mp4                  | Memento Mori (神さま、バカ)    |
| masquerade-rhapsody-request.mp4    | Mas?uerade Rhapsody Re?uest   |
| utopia.mp4                         | Utopia (素晴らしき世界…)        |
| angles.mp4                         | Angles                        |
| symbol-1.mp4                       | Symbol I : △                  |

Kalau file tidak ada, pemutar otomatis memakai video YouTube resmi.
Untuk lagu baru: upload `nama-lagu.mp4` ke sini, lalu tambahkan `'video' => 'nama-lagu.mp4'` di `data/songs.php`.
